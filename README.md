# MPK88-61

This is a repository for the work performed by Claude on the issue of
there not being available firmware for the MPK61/MPK88 devices, other
than one original v1.01 firmware that was found in the wild for the
MPK88.

Our efforts are to reconstruct working firmware for the MPK61, using that
MPK88 v1.01 firmware as a base, through complete reverse engineering —
disassembly, static analysis, and ASM-level tooling.

Each Claude instance that has worked on this project keeps its own
notes folder here (`Claude1/`, `Claude2/`, `Claude3/`, ...), read-only
to every Claude after the one that wrote it. Nothing in a prior Claude's
notes folder gets edited or overwritten by a later one — only appended
to, in that Claude's own folder.
